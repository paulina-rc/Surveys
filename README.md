# Survey System 

Survey management system developed with **Flask + MySQL**.

## Features

- User registration and login
- Roles (Admin / User)
- Create surveys
- Answer surveys
- View results with charts
- User management

## Technologies

- Python
- Flask
- MySQL
- HTML
- CSS
- Chart.js

## Installation

Clone repository:

```bash
git clone https://github.com/paulina-rc/Surveys.git
```

Install dependencies:

```bash
pip install flask mysql-connector-python
```

Run:

```bash
python app.py
```

Open:

```txt
http://127.0.0.1:5000
```
